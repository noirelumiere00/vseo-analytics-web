# コンテキスト分析 × トレンド分析 統合フォーマット案

## 現状の構成

### コンテキスト分析（現行）
| セクション | 内容 |
|---|---|
| サマリー | 商品概要・AI要約 |
| S1: クライアント発信 | PR公式メッセージ・ターゲット・訴求ポイント・ソースリンク |
| S2: SNS反応 | TikTok/Instagram の支配的ナラティブ・ハッシュタグ・エンゲージメントパターン |
| S3: Web評判 | レビューサイトのセンチメント・強み/弱み・競合ポジショニング |
| ギャップ分析 | 届いている層 / 未開拓の層 / 競合ギャップ |
| コンテキストマップ | ペインポイント・訴求角度のカバー状況 |

### トレンド分析（現行）
| セクション | 内容 |
|---|---|
| 統計サマリー | クエリ数・動画数・ER中央値・PR率 |
| AIトレンドレポート | Markdown形式のインサイト・戦略 |
| パフォーマンス分類 | トレンド中 / 平均 / 低調 の動画分類 |
| 需要トレンドチャート | キーワードの鮮度・需要推移 |
| ハッシュタグ分析 | TOP タグ・パフォーマンス散布図・共起タグ |
| エンゲージメント詳細 | ER統計・フォロワー×ER散布図・尺別分析・投稿時間ヒートマップ・再生数分布 |
| PR/Ad・SEO分析 | 広告率・推定出稿額・SEOメタキーワード |
| トップ動画・クリエイター | 上位動画リスト・主要クリエイター |

## S2 統合パネルの詳細

S2が大きくなるため、内部を**2層構造**にする:

### 上段: 一目でわかるサマリー（常時表示）
- 支配的ナラティブ（定性 — 現S2）
- 統計KPI: 動画数 / ER中央値 / PR率 / トレンドスコア（定量 — 新規）
- パフォーマンス分類（トレンド中/平均/低調）

### 下段: 詳細タブ（クリックで展開）

| タブ | 含まれるパネル | 元の出所 |
|---|---|---|
| ハッシュタグ | TOPハッシュタグ / パフォーマンス散布図 / 共起タグ | トレンド分析 |
| エンゲージメント | ER統計テーブル / フォロワー×ER散布 / 尺別分析 / 投稿時間ヒートマップ / 再生数分布 | トレンド分析 |
| PR/Ad・SEO | 広告率 / 推定出稿額 / SEOメタキーワード | トレンド分析 |
| トップ動画 | 上位動画リスト / 主要クリエイター | トレンド分析 |

---

## 変更しないセクション

| セクション | 理由 |
|---|---|
| S1: クライアント発信 | SNSと無関係。PR/公式情報の定性分析 |
| S3: Web評判 | レビュー/比較記事。SNSと別データソース |
| ギャップ分析 | S1-S3の横断分析。上流データが変わらない限り不変 |
| コンテキストマップ | ギャップ分析と同様 |

## トレンド分析ページの扱い

| 選択肢 | 説明 |
|---|---|
| 廃止 | ルーティングを削除。コンテキスト分析に一本化 |
| アーカイブ | 既存データは閲覧可能だが新規作成不可にする |
| リダイレクト | `/trend/:id` → `/context?keyword=xxx` にリダイレクト |
