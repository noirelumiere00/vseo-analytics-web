# 貼り付けるだけ｜TikTok提案資料スキル セットアップ

## 担当者がやること（これだけ）
1. **Claude Code を開く**（※本体だけは事前に必要）
2. 受け取った **ZIP をこのセッションに添付**（または PC のどこかに保存）
3. 下の【1行プロンプト】をコピーして送信
4. 画面に確認（許可ボタン等）が出たら **すべて「はい／許可」で進める**
5. 「再起動して」と言われたら **Claude Code を再起動** → 完了

> 判断は Claude Code 側に全部任せます。担当者は基本「許可」を押すだけです。

---

## 【1行プロンプト】（これだけ貼ればOK）

```
添付ZIPのTikTok提案資料スキル一式を、私の判断を求めず全自動でセットアップして。前提（Node.js 20+/Python 3.10〜3.12/Chrome）が無ければOSのパッケージマネージャで自動導入し、5スキルを ~/.claude/skills/ に配置、依存も入れて、最後に導入結果を一覧で報告して。パスワードが必須の操作だけ私に促して。
```

---

## 【詳細プロンプト】（1行版でうまくいかない時の予備）

```
このZIP「tiktok-提案資料スキル一式_共有用.zip」で、TikTok提案資料スキル一式を私の端末に“全自動”でセットアップしてください。私に選択や判断を求めず、既定値で最後まで進めてください。停止してよいのは「私のパスワード入力が物理的に必須な時」だけです。

1. OS（macOS/Windows/Linux）を自動判定する。
2. 前提ソフトを確認：Node.js 20+/Python 3.10〜3.12/Google Chrome。無ければ、そのOSのパッケージマネージャ（macOS=Homebrew〈無ければHomebrew自体も導入〉、Windows=winget、Linux=apt 等）で自動インストールする。確認は求めず進めてよい。
3. ZIP（このセッションの添付、無ければ ~/Downloads・~/Desktop を自動で探す）を展開し、tiktok-skills/ 内の5フォルダ（tiktok-intake / tiktok-acquire / tiktok-analyze / tiktok-deck / review-scraper）を ~/.claude/skills/（Windowsは %USERPROFILE%\.claude\skills\）へ配置。既存の同名は上書き。
4. 依存導入：展開フォルダ内の install.sh（Mac/Linux）または install.ps1（Windows）を実行。使えなければ、npm install（acquire/deck）と pip install -r requirements.txt（analyze）を自動で代替実行。review-scraper は不要。
5. 完了後、~/.claude/skills/ に5スキルが置かれたかを確認し、結果を一覧で報告。最後に「Claude Code を再起動してください」と伝える。

途中失敗は成功に見せかけず、失敗内容と自動リカバリの試行結果を報告すること。
```

## 補足
- 確認プロンプトを毎回押すのも面倒な場合、Claude Code を「コマンド自動承認」の権限モードで起動しておくと、ほぼ無操作で完走できます（各自の設定・自己責任で）。
- TikTok取得の成否は端末やOSではなく“出口IPの評判”次第です（0件時は再試行 or 別回線）。
